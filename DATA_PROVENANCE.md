# Data provenance and reuse

| Component | Source | Public repository content |
|---|---|---|
| Case research | https://doi.org/10.1371/journal.pntd.0014444 | Aggregate study metrics and method description; no weekly source table or per-issue series |
| Weather | NASA POWER Daily API | Method description; no API keys or response archive |
| Flood | Global Flood Database v1, CC BY-NC 4.0 | Aggregate experimental metrics and official source links; no source raster copies |
| Survey maps | NAMRIA Ulysses maps, 2020 | Source description and official link; map images excluded pending reuse clarification |
| Story | Team Sentinella scenario | Synthetic neighbourhood, flood, risk and intervention data embedded in the demo |
| Sensors | Planned field workflow | Empty observation template; no real site measurements |

Source links: [NASA POWER](https://power.larc.nasa.gov/docs/services/api/temporal/daily/), [GFD](https://global-flood-database.floodbase.com/), [GFD catalog and licence](https://developers.google.com/earth-engine/datasets/catalog/GLOBAL_FLOOD_DB_MODIS_EVENTS_V1), [NAMRIA](https://namria.gov.ph/Downloads.aspx).

The research plan PDF describes the broader local experiment. Files it mentions are available in the local research package where appropriate and are not all distributed in this public demo.
